## Niger Flood Impact Analysis — 2025

### Project Overview

This project analyzes flood-impact data for Niger published through the Humanitarian Data Exchange (HDX), sourced from OCHA-related reporting. It demonstrates how Python, data visualization, Power BI, and Monitoring, Evaluation, Accountability and Learning (MEAL) approaches can support humanitarian needs assessment and evidence-based decision-making.

### Objectives

- Analyze reported flood impacts across Niger's regions.
- Summarize affected households, affected people, and housing damage.
- Develop regional comparisons and visualizations.
- Build an interactive Power BI dashboard.
- Identify data-quality issues and communicate limitations transparently.

### Tools and Technologies

- **Python:** pandas, data cleaning, aggregation, exploratory data analysis, and Matplotlib visualizations.
- **Jupyter Notebook:** reproducible analysis.
- **Power BI:** interactive dashboard, KPI cards, charts, and regional filtering.
- **MEAL:** indicator interpretation, data-quality assessment, reporting, and recommendations.

### Preliminary Findings

The initial analysis covered 62 source records across 8 regions.

| Indicator | Preliminary total |
|---|---:|
| Reported affected people | 473,734 |
| Reported affected households | 61,180 |
| Reported houses collapsed | 46,450 |
| Reported damaged cases | 1,974 |
| Regions represented | 8 |

**Important:** These figures are provisional sums of the source records. They should not be interpreted as independently verified national totals.

### Data Quality and Limitations

- Several department codes appear more than once. Their reporting units, possible overlap, and aggregation method require verification before finalizing totals.
- One missing value was identified in the road-damage indicator.
- This is secondary-data analysis; the figures have not been independently verified through field data collection.
- Missing values are not automatically treated as zero, and repeated records are not automatically deleted.
